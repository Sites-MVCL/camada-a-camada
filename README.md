# Camada a Camada

Trilha interativa e gamificada sobre **peeling** e **microagulhamento**: 6 missões e um desafio final,
com jogos, brilhos, níveis e selos. Cada missão traz o conteúdo e jogos curtos para fixar o que foi lido.

- Site: abra `index.html` (ou o endereço do GitHub Pages deste repositório).
- O progresso de cada pessoa fica salvo no próprio aparelho.

Material educativo introdutório. Não ensina a executar procedimentos e não substitui avaliação profissional.

Fontes: ANVISA (Diferenças entre cosméticos e outros produtos; Estética com segurança, 2025);
SBD (Peelings químicos); Ferreira AS, Aita DL, Muneratto MA. Microagulhamento: uma revisão.
Rev Bras Cir Plást. 2020;35(2):228-234. DOI: 10.5935/2177-1235.2020RBCP0037.
